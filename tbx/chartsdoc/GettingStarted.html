Getting Started

This toolbox contains MATLAB code and examples for the technical article Creating Specialized Charts with MATLAB Object-Oriented Programming.

A chart provides a task-specific application programming interface (API) for creating custom visualizations. Designing and implementing a chart not only provides a convenient API for end users, but also removes the need for users to manipulate low-level graphics objects.

The toolbox includes several diverse examples of custom MATLAB charts. You can inspect the source code, explore the features and functionality, and run examples demonstrating the use of each chart.

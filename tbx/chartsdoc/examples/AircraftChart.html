Aircraft Chart

Overview

The AircraftChart displays a triangulated surface representing an aircraft. The chart data comprises a triangulation object, such as that returned by the stlread function. The chart places the surface within a transform object (using hgtransform), which makes it straightforward to rotate the aircraft by specifying the required angle. The chart is equipped with the following methods for adjusting the aircraft's attitude:

  • roll
  • pitch
  • yaw
  • reset

Documentation

  • stlread: Create triangulation from STL file
  • hgtransform: Transform graphics objects
  • trisurf: Triangular surface plot
  • weboptions: Specify parameters for RESTful web service
  • webread: Read content from RESTful web service

Examples

Create a figure for the chart.

f = exampleFigure( "Name", "AircraftChart Example" );

Create the chart.

Create the chart, using the default triangulation. Reference: Airplane by Yorchmur, https://www.printables.com/model/34767-airplane, licensed under the Creative Commons Attribution 4.0 International License.

AC = AircraftChart( "Parent", f );

Adjust the aircraft's attitude.

AC.pitch( 5 )
AC.roll( 30 )

Reset the aircraft.

AC.reset()

Graphics Hierarchy Chart

Overview

The GraphicsHierarchyChart visualizes the MATLAB graphics hierarchy descending from a given graphics object using a graph plot. This chart is useful when debugging more complex visualizations or application components. The chart uses a recursive algorithm (kids2graph) to find the descendants of the given graphics object representing the root node of the tree. The chart also provides an option to include graphics objects with hidden handles. By default, only descendants with visible handles are shown. We can use the convenience function plotkids to create the chart.

Documentation

  • graph: Graph with undirected edges
  • plot: Plot graph nodes and edges
  • plotkids: Convenience function for creating a graphics hierarchy chart
  • kids2graph: Construct a graph listing the descendants of the given graphics object

Examples

Visualize data using a scatter plot.

Generate random data.

rng( "default" )
n = 100;
x = rand( n, 1 );
y = rand( n, 2 );

Create the scatter plot.

f = figure;
scatter( x, y, "filled" )
legend( "A", "B" )

Visualize the graphics hierarchy under the figure.

fchart = exampleFigure( "Name", "GraphicsHierarchyChart Example" );
GHC = plotkids( f, "Parent", fchart );

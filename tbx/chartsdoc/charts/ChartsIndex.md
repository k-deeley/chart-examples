# Chart Reference

Each chart reference page links to the class documentation and examples, source code listing, and chart-specific test code listing when a matching test exists.

## Section Contents

* [Aircraft Chart](landing/AircraftChart.md) - visualize an aircraft and modify its roll, pitch, and yaw.
* [Annulus Chart](landing/AnnulusChart.md) - visualize relative proportions in a data vector using an annulus.
* [Circular Net Flow Chart](landing/CircularNetFlowChart.md) - show directed flow relationships between categories.
* [Clock Chart](landing/ClockChart.md) - display an analog clock with scheduled updates.
* [Cylinder Chart](landing/CylinderChart.md) - plot data using stacked cylinders.
* [Edgeworth Bowley Chart](landing/EdgeworthBowleyChart.md) - plot utility curves and a Pareto-efficient contract curve.
* [Graphics Hierarchy Chart](landing/GraphicsHierarchyChart.md) - visualize the graphics hierarchy below a graphics object.
* [Implied Volatility Chart](landing/ImpliedVolatilityChart.md) - plot an implied volatility surface.
* [Induction Motor Chart](landing/InductionMotorChart.md) - visualize induction motor characteristics.
* [Line Gradient Chart](landing/LineGradientChart.md) - plot a variable-color curve.
* [Line Selector Chart](landing/LineSelectorChart.md) - select and highlight one line from a collection.
* [Polar Chart](landing/PolarChart.md) - plot circular data on a polar chart.
* [Radar Scope](landing/RadarScope.md) - plot radar blips and issue proximity alerts.
* [Rangefinder Chart](landing/RangefinderChart.md) - show median crossover and marginal adjacent values.
* [Sankey Chart](landing/SankeyChart.md) - illustrate flow between states.
* [Scatter Box Chart](landing/ScatterBoxChart.md) - combine a scatter plot with marginal box plots.
* [Scatter Density Chart](landing/ScatterDensityChart.md) - use color to show relative point density.
* [Scatter Fit Chart](landing/ScatterFitChart.md) - manage scattered data with a best-fit line.
* [Settlement Chart](landing/SettlementChart.md) - plot in-the-money option prices against strike prices.
* [Signal Trace Chart](landing/SignalTraceChart.md) - plot non-overlapping signal traces.
* [Snail Trail Chart](landing/SnailTrailChart.md) - plot excess returns against tracking errors.
* [Spider Chart](landing/SpiderChart.md) - compare values from distinct measurements on a web.
* [Ternary Chart](landing/TernaryChart.md) - plot three variables that sum to a constant.
* [Value At Risk Chart](landing/ValueAtRiskChart.md) - show a return distribution and value-at-risk metrics.
* [Waterfall Chart](landing/WaterfallChart.md) - show the cumulative evolution of an initial value.
* [Wind Rose Chart](landing/WindRoseChart.md) - display wind speed and direction on a polar histogram.

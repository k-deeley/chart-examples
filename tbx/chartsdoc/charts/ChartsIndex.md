# Chart Reference

Each chart reference page links to the class documentation and examples, source code listing, and chart-specific test code listing when a matching test exists.

## Section Contents

* [Aircraft Chart](landing/AircraftChart.md) - Visualize an aircraft and modify its roll, pitch, and yaw
* [Annulus Chart](landing/AnnulusChart.md) - Visualize relative proportions in a data vector using an annulus (ring)
* [Circular Net Flow Chart](landing/CircularNetFlowChart.md) - Show directed to/from relationships between pairs of categories
* [Clock Chart](landing/ClockChart.md) - Display an analog clock, using a timer to schedule regular updates
* [Cylinder Chart](landing/CylinderChart.md) - Plot data using stacked cylinders
* [Edgeworth Bowley Chart](landing/EdgeworthBowleyChart.md) - Plot the utility curves of two individuals and the derived Pareto-efficient contract curve
* [Graphics Hierarchy Chart](landing/GraphicsHierarchyChart.md) - Visualize the graphics hierarchy descending from a given graphics object
* [Implied Volatility Chart](landing/ImpliedVolatilityChart.md) - Plot an implied volatility surface as a function of the option strike price and time to expiry
* [Induction Motor Chart](landing/InductionMotorChart.md) - Display the operating point of an induction motor in speed-torque coordinates
* [Line Gradient Chart](landing/LineGradientChart.md) - Plot a variable-color curve against a date/time vector
* [Line Selector Chart](landing/LineSelectorChart.md) - Display a collection of line plots and select one to highlight
* [Polar Chart](landing/PolarChart.md) - Polar line graph of dependent numeric variables plotted against independent circular data
* [Radar Scope](landing/RadarScope.md) - Plot a set of blips on a radar scope and issue proximity alerts
* [Rangefinder Chart](landing/RangefinderChart.md) - Bivariate scatter plot showing the crossover point of the marginal medians and lines indicating the marginal adjacent values
* [Sankey Chart](landing/SankeyChart.md) - Illustrate the flow between different states
* [Scatter Box Chart](landing/ScatterBoxChart.md) - Bivariate scatter plot with marginal boxplots
* [Scatter Density Chart](landing/ScatterDensityChart.md) - Bivariate scatter plot using color to indicate relative density of the data points
* [Scatter Fit Chart](landing/ScatterFitChart.md) - Manage bivariate scattered data together with the line of best fit
* [Settlement Chart](landing/SettlementChart.md) - Plot in the money option prices against strike prices
* [Signal Trace Chart](landing/SignalTraceChart.md) - Plot non-overlapping signal traces against a numeric time vector
* [Snail Trail Chart](landing/SnailTrailChart.md) - Plot excess returns against tracking errors for an asset relative to a benchmark
* [Spider Chart](landing/SpiderChart.md) - Plot and compare values from distinct measurements on a web
* [Ternary Chart](landing/TernaryChart.md) - Barycentric plot of three variables summing to a constant
* [Value At Risk Chart](landing/ValueAtRiskChart.md) - Plot the distribution of a return series together with its value at risk metrics and a distribution fit
* [Waterfall Chart](landing/WaterfallChart.md) - Cumulative bar chart visualizing the evolution of an initial value
* [Wind Rose Chart](landing/WindRoseChart.md) - Display wind speed and direction data on a polar histogram

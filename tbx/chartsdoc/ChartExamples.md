# Chart Reference

Each chart reference page links to class documentation with examples, source
code listing, and chart-specific test code listing when a matching test
exists.

## Section Contents

* [`AircraftChart`](charts/AircraftChart.md) - visualize an aircraft and modify its roll, pitch, and yaw.
* [`AnnulusChart`](charts/AnnulusChart.md) - visualize relative proportions in a data vector using an annulus.
* [`CircularNetFlowChart`](charts/CircularNetFlowChart.md) - show directed flow relationships between categories.
* [`ClockChart`](charts/ClockChart.md) - display an analog clock with scheduled updates.
* [`CylinderChart`](charts/CylinderChart.md) - plot data using stacked cylinders.
* [`EdgeworthBowleyChart`](charts/EdgeworthBowleyChart.md) - plot utility curves and a Pareto-efficient contract curve.
* [`GraphicsHierarchyChart`](charts/GraphicsHierarchyChart.md) - visualize the graphics hierarchy below a graphics object.
* [`ImpliedVolatilityChart`](charts/ImpliedVolatilityChart.md) - plot an implied volatility surface.
* [`InductionMotorChart`](charts/InductionMotorChart.md) - visualize induction motor characteristics.
* [`LineGradientChart`](charts/LineGradientChart.md) - plot a variable-color curve.
* [`LineSelectorChart`](charts/LineSelectorChart.md) - select and highlight one line from a collection.
* [`PolarChart`](charts/PolarChart.md) - plot circular data on a polar chart.
* [`RadarScope`](charts/RadarScope.md) - plot radar blips and issue proximity alerts.
* [`RangefinderChart`](charts/RangefinderChart.md) - show median crossover and marginal adjacent values.
* [`SankeyChart`](charts/SankeyChart.md) - illustrate flow between states.
* [`ScatterBoxChart`](charts/ScatterBoxChart.md) - combine a scatter plot with marginal box plots.
* [`ScatterDensityChart`](charts/ScatterDensityChart.md) - use color to show relative point density.
* [`ScatterFitChart`](charts/ScatterFitChart.md) - manage scattered data with a best-fit line.
* [`SettlementChart`](charts/SettlementChart.md) - plot in-the-money option prices against strike prices.
* [`SignalTraceChart`](charts/SignalTraceChart.md) - plot non-overlapping signal traces.
* [`SnailTrailChart`](charts/SnailTrailChart.md) - plot excess returns against tracking errors.
* [`SpiderChart`](charts/SpiderChart.md) - compare values from distinct measurements on a web.
* [`TernaryChart`](charts/TernaryChart.md) - plot three variables that sum to a constant.
* [`ValueAtRiskChart`](charts/ValueAtRiskChart.md) - show a return distribution and value-at-risk metrics.
* [`WaterfallChart`](charts/WaterfallChart.md) - show the cumulative evolution of an initial value.
* [`WindRoseChart`](charts/WindRoseChart.md) - display wind speed and direction on a polar histogram.

## Examples

Examples are included in the class documentation page for each chart.

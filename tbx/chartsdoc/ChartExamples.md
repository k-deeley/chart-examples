# Chart Examples

Each page describes one custom chart class and provides example code.

* [`AircraftChart`](examples/AircraftChart.md) - visualize an aircraft and modify its roll, pitch, and yaw.
* [`AnnulusChart`](examples/AnnulusChart.md) - visualize relative proportions in a data vector using an annulus.
* [`CircularNetFlowChart`](examples/CircularNetFlowChart.md) - show directed flow relationships between categories.
* [`ClockChart`](examples/ClockChart.md) - display an analog clock with scheduled updates.
* [`CylinderChart`](examples/CylinderChart.md) - plot data using stacked cylinders.
* [`EdgeworthBowleyChart`](examples/EdgeworthBowleyChart.md) - plot utility curves and a Pareto-efficient contract curve.
* [`GraphicsHierarchyChart`](examples/GraphicsHierarchyChart.md) - visualize the graphics hierarchy below a graphics object.
* [`ImpliedVolatilityChart`](examples/ImpliedVolatilityChart.md) - plot an implied volatility surface.
* [`InductionMotorChart`](examples/InductionMotorChart.md) - visualize induction motor characteristics.
* [`LineGradientChart`](examples/LineGradientChart.md) - plot a variable-color curve.
* [`LineSelectorChart`](examples/LineSelectorChart.md) - select and highlight one line from a collection.
* [`PolarChart`](examples/PolarChart.md) - plot circular data on a polar chart.
* [`RadarScope`](examples/RadarScope.md) - plot radar blips and issue proximity alerts.
* [`RangefinderChart`](examples/RangefinderChart.md) - show median crossover and marginal adjacent values.
* [`SankeyChart`](examples/SankeyChart.md) - illustrate flow between states.
* [`ScatterBoxChart`](examples/ScatterBoxChart.md) - combine a scatter plot with marginal box plots.
* [`ScatterDensityChart`](examples/ScatterDensityChart.md) - use color to show relative point density.
* [`ScatterFitChart`](examples/ScatterFitChart.md) - manage scattered data with a best-fit line.
* [`SettlementChart`](examples/SettlementChart.md) - plot in-the-money option prices against strike prices.
* [`SignalTraceChart`](examples/SignalTraceChart.md) - plot non-overlapping signal traces.
* [`SnailTrailChart`](examples/SnailTrailChart.md) - plot excess returns against tracking errors.
* [`SpiderChart`](examples/SpiderChart.md) - compare values from distinct measurements on a web.
* [`TernaryChart`](examples/TernaryChart.md) - plot three variables that sum to a constant.
* [`ValueAtRiskChart`](examples/ValueAtRiskChart.md) - show a return distribution and value-at-risk metrics.
* [`WaterfallChart`](examples/WaterfallChart.md) - show the cumulative evolution of an initial value.
* [`WindRoseChart`](examples/WindRoseChart.md) - display wind speed and direction on a polar histogram.

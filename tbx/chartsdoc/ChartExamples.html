Chart Examples

Each page describes one custom chart class and provides example code.

  • AircraftChart - visualize an aircraft and modify its roll, pitch, and yaw.
  • AnnulusChart - visualize relative proportions in a data vector using an annulus.
  • CircularNetFlowChart - show directed flow relationships between categories.
  • ClockChart - display an analog clock with scheduled updates.
  • CylinderChart - plot data using stacked cylinders.
  • EdgeworthBowleyChart - plot utility curves and a Pareto-efficient contract curve.
  • GraphicsHierarchyChart - visualize the graphics hierarchy below a graphics object.
  • ImpliedVolatilityChart - plot an implied volatility surface.
  • InductionMotorChart - visualize induction motor characteristics.
  • LineGradientChart - plot a variable-color curve.
  • LineSelectorChart - select and highlight one line from a collection.
  • PolarChart - plot circular data on a polar chart.
  • RadarScope - plot radar blips and issue proximity alerts.
  • RangefinderChart - show median crossover and marginal adjacent values.
  • SankeyChart - illustrate flow between states.
  • ScatterBoxChart - combine a scatter plot with marginal box plots.
  • ScatterDensityChart - use color to show relative point density.
  • ScatterFitChart - manage scattered data with a best-fit line.
  • SettlementChart - plot in-the-money option prices against strike prices.
  • SignalTraceChart - plot non-overlapping signal traces.
  • SnailTrailChart - plot excess returns against tracking errors.
  • SpiderChart - compare values from distinct measurements on a web.
  • TernaryChart - plot three variables that sum to a constant.
  • ValueAtRiskChart - show a return distribution and value-at-risk metrics.
  • WaterfallChart - show the cumulative evolution of an initial value.
  • WindRoseChart - display wind speed and direction on a polar histogram.
